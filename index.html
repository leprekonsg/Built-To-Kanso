010 · Evidence tiers

Every recommendation
carries one of five.

The Wind Audit is a design simulation report, not professional engineering certification. The system guarantees that displayed options pass the current rule engine and compliance filters. It does not certify renovation feasibility.

Official constraint

Public rule or dataset

HDB, SCDF, NEA, or other authority context. Constraint first, interpretation second.

Template fact

Curated plan geometry

Fixed elements, openings, floor, compass, and user-entered conditions. Ruler, not promise.

Heuristic estimate

Bounded rule engine

Plan-derived inference from environmental literature and declared assumptions.

Weather context

Live or historical signal

NEA wind and weather context that helps time a behavior, not certify a home.

Prototype visualisation

Browser simulation

Live WebGPU LBM or generated visual. Useful preview, not a measurement of your actual unit.

The honest line

A hypothesis, not a measurement

Any recommendation is a design hypothesis. The studio does not certify renovation, engineering, or Feng Shui.

011 · HDB compliance

Four states.
One is non-negotiable.

Built-To-Kanso never generates renders that imply illegal works. Household shelters are SCDF-protected civil defence shelters; modifications require regulatory review. The system blocks the action with citable language.

Decorative · furniture only
